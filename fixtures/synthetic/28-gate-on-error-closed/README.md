# 28-gate-on-error-closed

The batch of `08-mcp-batch-mixed` under `policy.gate-closed.json`, where the gate is live with `on_error: closed` and an acknowledgement that asks for `{token}`, which a gate cannot fill, so the rule throws a `TypeError` on the declaration: the declaration call is answered with the JSON-RPC error `-32000 "declaration gate unavailable"`, the batch's other call (tools/list) forwards and is answered, the origin's tools list still goes out with the declaration tool listed first (the response path did not fail), the gate records `errored` with reason `TypeError; on_error closed: declaration refused` and then `applied` for the amended tools list; no `scope.declaration/1` record (plan J3.1 steps 4 and 6). A closed gate never takes the customer's MCP server down with it.

Files: `request.json`, `upstream.json`, `policy.json` (a pointer to the closed-gate variant of the toy policy, derived by `scripts/fixture-policies.mjs`), `facts.json`, `expected.json` (generated by the Node run and reviewed line by line, the decisions' modes and outcomes included), `oracle.json` (the oracle's sensor has no `on_error`).
