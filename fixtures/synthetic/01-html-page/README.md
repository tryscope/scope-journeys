# 01-html-page

A docs page, HTML face, read by Claude Code's fetcher. The page gets a reference minted for this serve; every inject rule whose pattern matches applies (the MCP url, the API samples' setup and intent header lines, the internal links, the installer tarball, the carry note, the finder note); the face rule is skipped (not implemented in 0.1). The record carries the page facts and one decision per rule that matched.

Files: `request.json` (what arrived), `upstream.json` (what the origin answers), `policy.json` (a pointer to the toy policy or an inline document), `facts.json` (what the platform supplies), `expected.json` (the masked canonical response, the forwarded request and the records, generated by the Node run and reviewed line by line: the status and the headers, the forwarded request, every record field).
