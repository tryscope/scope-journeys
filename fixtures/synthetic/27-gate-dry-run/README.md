# 27-gate-dry-run

The batch of `08-mcp-batch-mixed` (tools/list and declare_intent) under `policy.dryrun.json`, where the gate is `dry_run`: nothing is answered locally, the whole batch forwards to the origin, whose fixture answers the tools list and "Unknown tool: declare_intent"; the response goes out unamended; the gate records one `would_apply` decision whose reasons are the live ones (`declaration answered`, `tools/list amended`); no `scope.declaration/1` record, because nothing was collected; `scope.gateway` counts 0 declared and 2 forwarded.

Files: `request.json`, `upstream.json`, `policy.json` (a pointer to the dry-run variant of the toy policy), `facts.json`, `expected.json` (generated by the Node run and reviewed line by line, the decisions' modes and outcomes included), `oracle.json` (the oracle's sensor has no dry run).
