# 25-probe

The probe `journeys doctor` sends: `GET /.well-known/journeys-probe?journeys_probe=<nonce>` is answered by the sensor itself with 204 and `x-journeys-probe: received`, never forwarded (0 forwarded requests, although the origin would answer 404), and recorded as one `scope.request/1` with `scope.route: passthrough`, the query kept (`journeys_probe=<nonce>`) and the client's facts, so the control plane's `journey_probe_find` can report which facts arrived. Policy-independent: the same answer under the forward-only default.

Files: `request.json` (what arrived), `upstream.json` (what the origin would answer: it is never asked), `policy.json` (a pointer to the toy policy), `facts.json` (what the platform supplies), `expected.json` (the masked canonical response, the forwarded request and the records, generated by the Node run and reviewed line by line: the status and the headers, the forwarded request, every record field, and the probe's own answer).
