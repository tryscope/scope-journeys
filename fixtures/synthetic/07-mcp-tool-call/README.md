# 07-mcp-tool-call

A plain tool call through the gate: forwarded as received, the answer untouched, no gate decision (a rule that does not match records nothing).

Files: `request.json` (what arrived), `upstream.json` (what the origin answers), `policy.json` (a pointer to the toy policy or an inline document), `facts.json` (what the platform supplies), `expected.json` (the masked canonical response, the forwarded request and the records, generated by the Node run and reviewed line by line: the status and the headers, the forwarded request, every record field).
